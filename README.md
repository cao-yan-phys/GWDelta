# GWDelta

[![Docs workflow status](https://github.com/cao-yan-phys/GWDelta/actions/workflows/docs.yml/badge.svg?branch=main)](https://github.com/cao-yan-phys/GWDelta/actions/workflows/docs.yml?query=branch%3Amain)

GWDelta is a toolkit for fast single-detector and detector-network response calculations for space-based gravitational-wave detectors, focusing on LISA-like triangular constellations. See [the documentation](https://cao-yan-phys.github.io/GWDelta/) for details.
